# Associazione Nuovi Orizzonti APS — landing

Pagina di presentazione dell'associazione Nuovi Orizzonti APS (Bisacquino, PA).

- `index.html` — la pagina, in un solo file (HTML e CSS).
- `assets/` — logo e carattere Montserrat.

Sito statico: non richiede installazione né compilazione. Per vederlo basta aprire `index.html` nel browser.
